## 复现01数据包

需要Python 3.12。克隆后安装固定依赖，再离线重建和验收：

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r data_delivery_01/requirements.txt
python data_delivery_01/pipeline.py rebuild --output data_delivery_01/rebuilt_data
python data_delivery_01/pipeline.py validate --output data_delivery_01/rebuilt_data
```

除首次安装依赖外，以上重建及验收无需网络。生成的数据文件应与冻结快照保持同一SHA256；验收清单里的运行环境信息可能因新机器环境不同而改变。请勿覆盖冻结的data和raw目录。

## 团队协作

1. 按任务卡分工，从main建立分支，例如`task02-main-model`、`task03-benchmarks`、`task04-report`。
2. 模型与评价必须使用同一冻结版本和同一推荐子集，不因检验期表现调整股票池或参数。
3. 每次提交附运行命令、输入版本、输出和失败记录；通过Pull Request合并，由对应负责人复核。
4. 原始数据及清单不原地覆盖。修订数据时建立新版本并记录差异，通知下游重跑。
5. 不提交数据库密码、token、个人环境或缓存。原论文完整本保留本地，公开副本移除了数据库连接附录。
