# 适合当前研究的补充baseline

2026-11-26更新：下表四个优先基准已按用户要求实现并纳入task03/results；选定的固定规则与下表一致，未按结果反选窗口或持仓数。实现见task03/simple_baselines.py，统一比较与原PDF核查见[分析报告](../analysis/README.md)。后文HRP与Qlib仍是可选扩展，尚未实现。

当前主模型同时承担股票稀疏选择和权重配置。现有MV、CVaR、VaR同样依赖估计期收益均值，因此应增加不依赖均值的配置对照，再增加简单、可解释的选股对照。

## 已实现的四项基准

| baseline | 建议固定规则 | 主要回答的问题 |
|---|---|---|
| 非负全局最小方差GMV | min u'Σu，u>=0、sum(u)=1，使用同一359日估计期 | 去掉不稳定的历史收益均值后，纯风险配置是否更稳健 |
| 波动率倒数加权 | 用估计期样本标准差，u_i∝1/s_i；零波动须明确失败或排除 | 复杂优化相对简单风险分散规则的增量 |
| 横截面动量Top20等权 | 决策日计算过去126个交易日、剔除最近21日的累计复权收益，选前20只；代码打破并列 | 主模型的收益选择能力相对简单动量信号如何 |
| 低波动Top20等权 | 决策日前60个交易日的收益样本标准差升序，取20只；代码打破并列 | 复杂风险模型相对简单低波动选股的增量 |

上述窗口与20只持仓是供下一版事先固定的建议，不是从本次样本外结果选出的最优设置。GMV与波动率倒数属于配置方法；动量与低波动Top20属于选股方法，应在报告中注明这一差别。

[PyPortfolioOpt官方文档](https://pyportfolioopt.readthedocs.io/en/latest/MeanVariance.html)提供成熟的最小波动配置接口，可作为GMV实现参考。动量排序与交易框架可参考[Backtrader官方动量策略示例](https://www.backtrader.com/blog/2019-05-20-momentum-strategy/momentum-strategy/)。该示例还含趋势过滤和调仓逻辑；采用上表简化收益排序时，应命名为自定义的简单动量baseline，不能冒称完整复现示例策略。

## 可选的进一步对照

- **层次风险平价HRP**：已有[PyPortfolioOpt开源实现及文档](https://pyportfolioopt.readthedocs.io/en/latest/OtherOptimizers.html)，不需要预测收益均值。比波动率倒数多考虑相关性结构，可在基础四项完成后增加。
- **Qlib Linear/Ridge + Alpha158 + TopK**：Qlib[官方基准表](https://github.com/microsoft/qlib/blob/main/examples/benchmarks/README.md)包含Linear/Alpha158及CSI500配置说明，[策略文档](https://qlib.readthedocs.io/en/latest/component/strategy.html)提供预测分数到组合的接口。可作为普通机器学习选股的扩展，而非当前优化模型的直接等价对照。需要新增OHLCV特征、未来收益标签、按时间训练/验证及交易规则；不能把其公开历史收益数字复制到本项目主表。

## 如何保持比较可信

第一版扩展继续用同一100只研究池，在6月30日确定全部信号和权重，7月1日收盘建仓，沿用一次持有、88日、相同成本口径。简单动量在此版本应明确命名为“单次排序建仓”，不能等同于每月轮动策略。

若要比较常见月度轮动选股，需另建统一的月度调仓实验：主模型与其他基准都在相同日期重估，信号只用当时可知信息，并采用同一成交延迟、费用、换手与不可交易处理。仅让动量每月调仓、其他方法持有到底，会混入交易频率差异。

本次数据的历史成分前视、存活偏差和供应商复权代理仍适用于所有新增方法。财报估值、质量或盈利因子需另补带公告可得时点的数据，不能用当前截面回填历史。
