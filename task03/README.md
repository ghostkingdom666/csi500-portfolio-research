**交接结论。** 已用第 1 人冻结数据包与第 2 人交付权重跑通唯一公共评价：2026-07-01 收盘建仓、2026-07-02 起计收益、持有至 2026-11-10，共 88 个收益日、零成本、不再平衡。14 个策略模型全部 `optimal`，无失败或不可行行；第 15 行是中证500价格指数参照（`status=reference`，不参与排名）。五方法主比较中，等权 −30.63% 最好，VaR 启发式 −34.92% 次之，CVaR(95%) −43.09%，非负 ℓ1 主模型 −53.09%，均值—方差 −63.54%；同期中证500价格指数 −26.39%。全部方法在该窗口均为负收益，差异主要来自暴露与波动，不能据此宣称任何方法长期占优。

**关键观察（均限于本窗口）**

1. 估计期到检验期发生明显状态切换：ℓ1 主模型估计期日均收益 0.7024%、日波动 2.1596%，检验期日均 −0.80%、日波动 3.40%。
2. 均值—方差在估计期满足 3% 日频波动上限，检验期实现年化波动 72.91%，说明风险约束**只对估计期成立**，不能外推为风险保证。
3. VaR 启发式与等权持仓数都是 100，但前者按估计期均值在可行候选中选择，检验期收益略低于等权；它只是启发式，不是全局最优 VaR。
4. 数量约束配对在 20 只小池上差异很小（−55.59% vs −55.89%），单窗口不足以支持"数量约束改善样本外表现"的结论；任务2 的估计期目标值方向与之相反，两者都应如实报告。
5. 三个 VaR 种子结果差异约 0.1 个百分点，说明随机候选预算下结果较稳定，但仍不构成最优性证据。

## 口径与预登记

- 建仓 2026-07-01 收盘，V0=1，首笔收益 2026-07-02，截止 2026-11-10，88 个收益日；
- `V_t = Σ u_i ∏(1+r_{s,i})`，一次建仓持有，权重随价格漂移；
- 累计 `V_end/V_0−1`；年化 `(V_end/V_0)^(252/n)−1`；年化波动 `sqrt(252)·std(ddof=1)`；夏普 `sqrt(252)·mean/std`，rf=0；最大回撤峰值含初始 1；
- 预登记参数（`protocol.json`，2026-11-20 冻结，未查看检验期收益）：MV `σ_max=0.03`；CVaR 主情景 α=0.95、`L_max=0.03`，敏感性 α=0.99、`L_max=0.045`；VaR 启发式 α=0.95、`L_max=0.03`、budget=3000、seeds={0,1,2}；
- 风险量不得混用：任务2 的 `σ=0.04` 是目标向量构造参数（非硬约束），本任务 `σ_max` 是均值—方差硬上限，`L_max` 是损失口径限额。详见 `contract.md` 第 3 节。

## 复现

在仓库根目录（Python 3.12+，依赖 numpy/pandas/scipy/mpmath/matplotlib）：

```bash
python task03/test_eval.py                 # 12 组人工可核对测试
python task03/run.py --output task03/results   # 读取冻结数据与 task02 权重，重写结果
python task03/verify.py                    # 独立复算净值、指标与任务2目标估计
python task03/make_charts.py               # 由 nav.csv 重生成图表
```

### 2026-11-21 自查记录

- **约束绑定**：CVaR95 组合估计期经验 CVaR = 3.000%（限额 3.000%），CVaR99 = 4.500%（限额 4.500%）；MV 估计期日波动 = 3.000%（上限 3.000%）；VaR 启发式经验 VaR 为 2.905%–2.995%（限额 3.000%，受候选预算限制未贴边）。

- **数据合理性**：检验期中证500指数最差单日 −5.55%、年化波动 31.85%，与等权组合相关系数 0.977。个股日收益超 ±11% 的样本占 1.6%，其中 3 个落在收益窗口内的 10% 涨跌幅主板样本（600601.SH 两次、000737.SZ 一次），1 个在建仓日窗口外（601162.SH）。核查发现 `close_adj/close_raw` 比值在样本期内频繁小幅变动（日均绝对差 0.127%、p95 0.48%），并非只在除权日跳变，与严格后复权因子不一致；改用原始价格重算买入持有累计收益，比官方口径低 0.92–3.57 个百分点（等权 −31.55% vs −30.63%，ℓ1 −55.45% vs −53.09%），**方法排序不变**。该差异属第 1 人披露的“供应商复权代理”口径，建议数据负责人核验，本次结论对复权口径不敏感。
- **复现性**：连续两次运行 `nav.csv`、`weights_benchmarks.csv`、`checks.txt` 哈希一致；`metrics.csv`、`comparison.csv` 含求解墙钟 `seconds`，文件哈希随机器变化，`run_manifest.json` 的 `outputs` 以当次运行文件为准。
