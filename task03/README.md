## 公共评价口径

- 冻结数据为同一 100 只研究子集；2026-07-01 收盘建仓，2026-07-02 起计收益，至 2026-11-10，共 88 个收益日。
- 一次建仓持有，`V_t = Σ u_i ∏(1+r_{s,i})`，权重随价格漂移；零成本，不每日恢复比例。
- rf=0、D=252、标准差 ddof=1；最大回撤峰值包含初始净值 1。年化收益是短窗口的数学折算，不能作为长期预期。
- `role=main` 为 `l1_cv`、`equal`、`mv`、`cvar_a95`、`var_a95_s0`、`gmv`、`inverse_volatility`、`momentum_top20`、`low_volatility_top20` 九行，当前任务2交付下共20行。原 `l1_eta_0.01` 与其他固定 η 行均为 `sensitivity`；VaR 三个种子全部保留，seed 0 为主情景，不按检验收益选种子。
- 20 只小池的 `mv_continuous`/`mv_cardinality` 为 `extension`，单独成表；中证500价格指数是 `reference`，不参与策略排名。

## 新增固定简单基准

`simple_baselines.py` 的四个方法仅接收估计期收益，输出按 `asset_id` 标注的全100行投入权重及诊断。估计期为2025-01-02至2026-06-30，共359个收益日，均不读取7月1日或检验期收益来形成信号。

| model_id | 固定规则 |
|---|---|
| `gmv` | 完整359日、ddof=1样本协方差，最小化 `u'Σu`，`u>=0, sum(u)=1`，无收益目标；SLSQP并检查KKT |
| `inverse_volatility` | 完整359日、ddof=1样本标准差，`u_i ∝ 1/s_i`；任一零或非有限波动明确失败，不静默删股 |
| `momentum_top20` | `prod(1+R[-126:-21])-1` 降序，按 `asset_id` 字典升序破并列，前20只各5%；信号区间2025-12-18至2026-05-29共105日，剔除2026-06-01至2026-06-30的21个最近收益日 |
| `low_volatility_top20` | 最近60个收益日（2026-04-01至2026-06-30）的ddof=1标准差升序，同样按代码破并列，前20只各5% |

GMV与波动率倒数是配置对照；动量与低波动Top20是选股对照。动量仅单次排序建仓，不是月度轮动。126/21/60/20来自既定baseline建议，本次为有日期的回溯新增，不重新声称事前登记，不按检验结果调参。所有方法沿用7月1日收盘建仓、88日买入持有和零成本。

`run_manifest.json` 对四者记录完整估计区间、样本数、固定参数、目标与诊断；两个选股方法额外记录实际信号起止日、全部100只评分、完整排序和选中资产。`comparison.csv` 的 `K` 对两个Top20为20，其余新增方法不设持仓数限制。

## 风险统计与 2026-11-26 更正

估计期等权的日损失统计，按冻结数据动态计算并输出 `risk_statistics.csv`：

| α | 经验 VaR | 经验 CVaR |
|---|---:|---:|
| 95% | 3.1404997% | 4.2619536% |
| 99% | 4.2893239% | 6.8470454% |

经验 VaR 取损失升序第 `ceil(αT)` 个；CVaR 使用 `min_ζ ζ + Σ(L_t−ζ)^+ / [T(1−α)]`。原协议把 **VaR95 3.14%、VaR99 4.29% 误写为 CVaR**，因此原有“等权 CVaR 略高于限额”的依据不成立。

保留原限额：MV 日波动 3%，CVaR95/VaR95 日损失 3%，CVaR99 日损失 4.5%。本次是有日期的回溯更正，不能重新声称事前登记，也没有按检验期收益重新选择限额。`protocol.json` 保留原日期，并在 `revisions` 中记录更正。

任务2 `sigma=0.04` 是原目标向量构造参数，用于原始系数的风险校准，并非归一化权重的风险硬约束；本任务 `sigma_max` 是估计期波动硬上限，`loss_max` 是估计期日损失限额。它们不是同一风险量，也不保证检验期风险。

## VaR 搜索与状态

每个种子的 **3000 是总候选预算**，按以下顺序构造：等权、全部单股顶点、可用的 CVaR95/CVaR99 解，再用 Dirichlet(1) 随机点补足。100 只资产且两组 warm start 均成功时，随机预算为 2897。warm start 仅使用估计期优化结果，候选在该估计期的 VaR 限额下再次检验。

在可行候选中最大化估计期样本均值，所选目标至少不劣于已纳入且满足 VaR 限额的 warm start。`run_manifest.json` 的 `benchmark_runs` 完整记录总预算、随机预算、种子、可行数、选中候选 ID/序号，以及各 warm start 的 ID、序号、按资产标注的权重、经验 VaR、目标和可行性。

成功状态为 `feasible_heuristic`，不声称全局最优；找不到可行候选为 `no_feasible_candidate`，不构成整个可行域不存在解的证明。`optimal` 与 `feasible_heuristic` 的有效权重进入评价；失败状态原样保留，净值和业绩为空。CVaR 线性规划与 MV 的状态保持各自求解器含义。

## 复现与检查

在仓库根目录运行（Python 3.12+，numpy/pandas/scipy/mpmath/matplotlib）：

```bash
python task03/test_eval.py
python task03/test_simple_baselines.py
python task03/run.py --output task03/results
python task03/verify.py --output task03/results
python task03/make_charts.py
```

`run.py` 先验证冻结数据哈希、资产顺序、日期、缺失、任务2可评价权重及估计期统计；检查失败停止。`verify.py` 独立重算净值、业绩、θ_s/θ_a/r_c、λ_max；从当前任务2 manifest 读取输出哈希，替代旧的固定权重哈希；并复算风险统计、重放 VaR 全部候选、检查 warm start 与原 CVaR 权重一致及失败空业绩。新增基准复核不调用生产函数：用中心化交叉积重建协方差并验证GMV的KKT，独立复算波动率倒数、复利动量和60日低波动评分、排序与权重。检查数量随上游模型和状态变化，以当次文本证据为准。

原22组测试保留失败/provenance约束；新增测试覆盖协方差对角1:4的GMV权重0.8/0.2及波动率倒数2/3、1/3、动量精确边界与最近21日剔除、低波动60日边界、代码破并列、非法K、历史不足、无效收益和零波动。真实冻结数据在临时目录端到端验证20行/9main、四者相同88日、仅估计期输入、全100行权重、manifest与独立复核，并在刷新输出哈希后故意篡改四种权重以验证规则/KKT检测。测试不会覆盖正式结果目录。
