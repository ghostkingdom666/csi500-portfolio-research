# 任务 2｜中证500主模型与持仓数量约束实验

**交接结论。** 采用数据负责人冻结的100只股票和359个估计交易日，主情景得到11只持仓。另取成交额排名前20只做配对实验，限制最多5只时，估计期组合的日均收益和波动均上升，按事先固定的均值—方差目标衡量，风险增加的代价超过收益增加。任务 3 已接入权重并生成样本外净值。主情景累计收益 −53.09%、最大回撤 −55.84%。复核范围、20 股配对及异常状态见[公共评价复核](公共评价复核.md)。

## 一页方法与结果（供报告采用）

2025-01-02至2026-06-30的日收益用于定权。数据版本为 csi500_20261111T020022_current_v1。500只候选中，469只符合估计期完整性要求，采用数据包选出的100只。主模型先从估计期样本均值、协方差构造常数响应，再以非负系数拟合响应。仅在求解结束后将系数除以系数和，得到全投资组合。日频参数 σ=0.04，主情景 η=0.01，λ=ηλ_max=0.01356213。目标响应 0.177813 是优化输入，不能解释为预期日收益。σ 也不保证实际组合日波动达到4%。

**100 股主模型。** 主情景持有 11 只，最大权重 18.04%，估计期日均收益 0.7024%，日波动 2.1596%。

**20 股同池对照。** 差值为“最多 5 只”减“连续配置”，时间取本次独立环境复跑的实测值。

| 指标 | 连续配置 | 最多 5 只 | 差值 |

| 持仓数 | 10 | 5 | −5 |
| 最大权重 | 25.00% | 25.00% | 0.00 个百分点 |
| 估计期日均收益 | 0.59854% | 0.61773% | +0.01919 个百分点 |
| 估计期日波动 | 2.31903% | 2.41196% | +0.09293 个百分点 |

表内收益、波动分别为 R u 的样本均值、样本标准差，描述初始权重对估计样本的暴露。主情景前三大持仓为宏和科技（18.04%）、多氟多（17.24%）、长飞光纤（16.30%），共51.58%。敏感性情景 η 依次取 0、0.0001、0.001、0.01、0.1，持仓依次为10、10、10、11、9只。非负 ℓ1 并未在所有情景下产生随 λ 严格递减的持仓数。

拓展按冻结流动性排名取前20，固定风险厌恶系数 γ=15、单股上限25%、K=5。20 只是任务卡建议规模的下界，便于整数求解和交叉复核；上限25%意味着至少需要4只，K=5保留了配置余地。γ=15作为固定风险偏好，仅用于这一对模型。σ与η采用任务卡建议值，使其他组员可在同一尺度复跑。连续与整数解的最小化目标分别为 −0.00195198 和 −0.00181411，数量约束使目标升高约0.00013787。SCIP 对两者均以 optimal 结束，报告的相对 gap 均为0。本次耗时以 results/runs.csv 的 seconds 为准。100只股票的 ℓ1 行仅用于说明主模型，不参与20只股票的同池差值计算。

**局限。** 数据包采用2026-11-10的当前成分股回溯，存在成分前视及存活偏差。供应商后复权收益是总回报的代理，部分序列存在供应商差异。固定参数和短估计窗也限制外推。历史数据建仓约定为7月1日收盘，首笔收盘到收盘收益为7月2日，估值截止11月10日。建仓可交易性及实际计账由公共评价确认。

## 公式、实现与原稿核对

完整目标估计公式见仓库根目录的《02_任务卡_主模型求解与研究扩展》。以下符号和代码对应同一冻结输入。

| 对象 | 定义、维度与实现 |
|---|---|
| R、μ、Σ | run.inputs 先核4项 SHA256，核对资产标签顺序与交易日历。只将估计日期的日收益转为浮点矩阵 R（T×N，小数）。models.target 计算列均值 μ（N）和分母 T−1 的样本协方差 Σ（N×N）。 |
| θ_s、θ_a、r_c | 用线性方程解 Σx=μ，得 θ_s=μᵀx。adjusted_theta 按任务卡校正，以 log B_x=betaln(a,b)+log(betainc(a,b,x)) 计算，a=N/2、b=(T−N)/2、x=θ_s/(1+θ_s)。r_c=σ(1+θ_a)/√θ_a，y 为 T 个 r_c。实测 θ_s=0.445229、θ_a=0.056483、协方差条件数615.67。 |
| w、λ | models.lasso 最小化 ‖Rw−y‖²+λΣw_i，w≥0，w 为 N 个原始系数。λ_max=max(0,2 max(Rᵀy))。列满秩时取 Rᵀd=(λ/2)1，对 y−d 做非负最小二乘；展开平方可知仅多一个与 w 无关的常数。重列时直接优化原目标。目标值和 KKT 均按原尺度重算。 |
| u | 主模型成功且系数和为正时，run.run 输出 u=w/Σw。持仓数阈值 u>10⁻⁸ 只用于报数，主模型权重不截尾。 |
| u、z、K | models.extension 最小化 γuᵀΣu/2−μᵀu，Σu_i=1，0≤u_i≤上限。整数版本加二元 z、u_i≤上限·z_i、Σz_i≤K。用线性目标和凸二次上图约束提交 SCIP，内部放大一万倍，导出时还原。去掉选择变量即同池连续对照。 |

**公开原稿第21—24页修复记录。** 保留样本协方差、目标校正及非负平方损失。原文按全窗口缺失删列，本次按冻结估计期研究池取列；输入已为小数，直接读取。以估计边界和流动性排名替代 Notebook 状态。原稿对协方差加 10⁻⁶ 再求逆，本次核查特征值后解未经扰动的线性方程。原稿直接积分及计算高次幂，改为对数域。原稿随机十折后平均各折最优 λ，本次按预设比例作敏感性。原稿原地清零 ≤0.0001 的系数再归一化，本次保留 w 和 u 两列。原稿用固定权重逐日点乘，本次只交初始建仓权重。代码重写，数量约束、输入哈希、异常检查和单测为新增内容。
