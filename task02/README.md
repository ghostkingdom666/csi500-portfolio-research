# 任务2：非负L1稀疏配置、随机十折与数量约束

2026-11-26按用户要求恢复随机十折。当前主模型是 `l1_cv`；`l1_eta_0.01`及其余η网格全部保留为补充敏感性。旧结果、旧协议和旧说明保存在 `archive/2026-11-26-before-cv/`。

## 主模型定位

这是利用历史收益矩阵构造的非负L1稀疏配置经验方法，不是未来收益预测器，也不承诺投入权重风险或样本外收益。输入是冻结的359×100估计期日简单收益矩阵，估计期为2025-01-02至2026-06-30。

求解 `min_{w>=0} ||r_c 1-Rw||² + lambda sum(w)`，然后令 `u=w/sum(w)`。w是回归系数，u才是全投资比例。目标构造保留原文μ、Σ和θ校正，使用样本协方差、线性方程与对数域不完全Beta计算。完整估计期响应0.1778133758不是预期日收益。

σ=0.04用于构造响应和十折的原始系数风险匹配。十折匹配 `Var(R_val w)`，归一化后的 `Var(R_val u)`另行记录；两者不能混同。原问题没有 `u'Σu<=σ²` 约束。

## 随机十折选lambda：主流程

`cross_validation.py`不新增sklearn依赖，使用与 `KFold(n_splits=10, shuffle=True, random_state=42)`一致的随机划分。

1. 只接收估计期R；每个交易行恰好在一个验证折中，其余作为该折训练行。
2. 每折从训练行重新估计μ、Σ、θ和响应，验证行不进入目标构造。
3. 按原附录实际调用 `np.linspace(0,10,100)`生成100个绝对lambda候选，包含两个端点。
4. 对每个候选求非负L1解，以验证方差误差 `abs(Var(R_val w, ddof=1)-sigma²)`选择折内lambda。精确并列时取较大lambda，与原稿的<=更新一致。
5. 零解和求解失败仍导出，但不作为可投资候选；某折没有有效候选则明确失败，不填造权重。
6. 十个折内最优lambda取算术平均，在完整估计期重新求解并归一化，得到l1_cv。

当前各折lambda为0.101010、0.101010、0.404040、0、0、0.101010、0.303030、0.303030、0.505051、0.404040，均值 **0.222222222222**。全估计期重求得到 **7只持仓**、最大权重 **26.7137%**，原始系数日波动 **4.1048%**，投入权重日波动 **2.7002%**。这些是估计期描述；样本外结果由任务3统一生成。

随机折保留原方法，但训练行可以晚于同折验证行，不能当作时间前推验证。本次修改发生在已知历史结果后，是回溯方法修订，不重新声称前瞻盲测。

## 固定eta：补充敏感性

保留eta∈{0,0.0001,0.001,0.01,0.1}，按 `lambda=eta*lambda_max`、`lambda_max=max(0,2max(R' y))`计算。它展示惩罚强度变化对持仓的影响，不从数据选择lambda，也不替代随机十折。

此分支中y和lambda同尺度变化。令 `y=c1, w=cv` 后目标整体乘c²，最终 `u=v/sum(v)`，所以σ和θ校正的尺度从投入权重中抵消。不能用此分支声称σ控制配置风险或θ校正改善配置。随机十折使用绝对lambda网格，是另一条选择规则；仍不提供硬风险保证。

## 持仓数量约束拓展

以估计期成交额排名前20只做同池对照。固定γ=15、单股上限25%、K=5，比较连续模型与最多5只的整数模型。目标 `gamma/2*u'Σu-mu'u`，两者仅相差数量约束。SCIP最优界、gap、节点、残差及耗时保留在runs。负目标函数值不是负收益率。20只拓展不能与100只基础方法混排。

Python 3.12+，依赖版本与任务3兼容：

```powershell
python -m pip install -r task02/requirements.txt

python task02/verify.py task02/results
```

| 文件 | 含义 |
|---|---|
| results/weights.csv | 8组组合的原始系数、投入权重、标签和状态 |
| results/runs.csv | 主模型/敏感性/拓展角色、选择方式、目标、风险与求解诊断 |
| results/cv_selection.json | 十折配置、目标、逐折索引、均值lambda及估计日期 |
| results/cv_folds.csv | 训练/验证交易日、逐折lambda和两种风险诊断 |

| results/manifest.json | 输入、代码及输出SHA256、模型定位、依赖版本 |

verify.py不调用CV或L1封装：以70位不完全Beta参照重算目标，直接调用SciPy数值例程复算每折路径，用协方差二次型核对验证方差，并核查lambda聚合、日期、最终8组权重、KKT和数量约束。哈希从当次manifest读取，不使用旧固定权重哈希。

现有主模型测试8项，CV测试8项，包含一资产闭式解、原随机划分、验证行不进入响应、两套风险区分、全零候选全折诊断，以及真实冻结数据端到端导出和部分候选失败后的独立验证。任务3以l1_cv作为主比较中的L1行，所有η行保留为敏感性。
