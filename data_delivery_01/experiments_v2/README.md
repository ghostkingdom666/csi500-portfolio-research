`csi500_rolling_v2` 由01冻结快照生成。快照含500只中证500候选股，448个研究交易日，数据截至2026-11-10。每个窗口按估计期数据选出嵌套的100、200、250、300只股票，四档共用本窗口的日期。建议用200只做第一组扩容对照，250只和300只检查规模敏感性。中证500已满足扩容需要。

估计期从2025-01-02开始，随窗口推进逐步扩展。前三个主窗口按连续双月划分，持有期互不重叠。11月剩余日期单列，原检验区间与主窗口重叠，仅用于前后对照。指数涨跌用建仓日收盘到窗口末日收盘计算，≥+5%标上涨，≤−5%标下跌，其余标震荡。市场标签在事后生成，选股和定权不使用该标签。现有数据只有一个完整上涨窗口，适合探索市场阶段敏感性。各窗口的估计样本长度和排名均可能变化，跨窗业绩差异也可能反映这些变化。

### 选股与质量

- 每窗469只通过估计期检查。要求所有估计交易日都有有限收益及非负有限成交额，价格无冲突或无效标记。按平均日成交额降序，证券代码升序打破并列。选股只读估计期数据。
- 所有组合均满足 `T > N + 2`，中心化收益矩阵均满列秩。最早一窗的300只版本只剩18个 `T − N − 2` 自由度余量，样本协方差条件数约为30.4万，200只约为6,794。02仍需检查目标估计量和求解稳定性。
- 现行 `l1_cv` 还要求每个训练折单独满足 `T_fold > N + 2`。5–6月窗口的十折各有288个训练日，该窗可用100、200、250只做十折对照，300只保留给满足全窗维度要求的实验。跨三个主窗口复用现行十折时，统一取200只或250只。
- 四档的持有期收益均无空值，已证实停牌的延续估值沿用01规则。11月短窗口中，中国稀土 `000831.SZ` 在拟建仓日已停牌，且在四档名单中均入选。该窗口需使用共同执行规则，或记为无法按计划建仓。原始状态证据和估值方法随包提供。
- 股票池来自2026-11-10的当前成分，仍有成分前视与存活偏差。日收益是供应商复权价格代理，指数为价格指数。本包提供模型和评价输入。若用已有窗口结果调整参数，后续需要独立检验期。

### 使用和复现

`data/windows.csv` 每行对应一个窗口和一个股票规模，含维度、条件数、建仓状态和缺失诊断。`data/manifest.json` 记录原快照版本、源文件和产物哈希。每个窗口目录包含以下文件。

|文件|用途|
|---|---|
|`assets.csv`|500只候选的覆盖、成交额、排名与 `in_100`、`in_200`、`in_250`、`in_300` 入选标记。另列建仓日价格和状态。|
|`estimation_returns.csv`|300只的估计矩阵。选参和定权使用本文件的所需列。|
|`holding_returns.csv`|300只的持有收益，首行是建仓日后首个收益。|
|`benchmark.csv`|建仓基准日收盘、日收益和从1开始的中证500价格指数净值。|
|`test_status_exceptions.csv`|拟建仓日及持有期的非正常交易状态、估值方法和证据路径（相对于01数据包）。|

例如读取5–6月的200只版本，估计、持有和各基准方法共用同一列顺序。

```python
from pathlib import Path
import pandas as pd

window = Path('data_delivery_01/experiments_v2/data/2026-05_06')
assets = pd.read_csv(window / 'assets.csv', dtype={'asset_id': str})
ids = assets.loc[assets['in_200'], 'asset_id'].tolist()
train = pd.read_csv(window / 'estimation_returns.csv', index_col='date')[ids]
hold = pd.read_csv(window / 'holding_returns.csv', index_col='date')[ids]
```

使用01相同的 Python、NumPy 和 pandas 环境，从仓库根目录离线复建。指定一个尚不存在的输出目录，脚本会先核对冻结输入的哈希。
