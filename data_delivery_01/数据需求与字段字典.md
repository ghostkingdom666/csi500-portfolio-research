# 01数据需求与字段字典

## 需求对照

|级别|收集项及用途|本版来源|缺失影响与处理|
|---|---|---|---|
|必需|500只成分及交易所，固定收集对象|中证官方xls|已取得当前500只；历史完整名单未核实，已批准降级并披露偏差|
|必需|日期、代码，唯一键与列标签|主源日线、官方名单|冲突阻止该键收益使用；代码字符串加.SH/.SZ|
|必需|原始收盘、复权收盘，收益与异常核查|东方财富fqt=0/2|不混源；缺价不补未知收益；估计期缺价资产不能进入子集|

|辅助|中证500价格指数，市场参照及日历交叉核验|东方财富指数日线|不替代500只股票，不增加优化方法|

## 价格与收益

`prices_long.csv`包括锚点，按date、asset_id排序，每一交易日每一候选股一行；缺失也占位。原始未对齐条数见cleaning_audit.csv。原始响应永不被清洗覆盖。

|字段|类型 / 单位|意义|
|---|---|---|
|date|string / YYYY-MM-DD|正式交易日；锚点为2024-12-31|
|asset_id|string|六位代码加交易所后缀，不能当整数|
|open_raw, high_raw, low_raw, close_raw|float / 元每股|未复权交易价；停牌延续时仅close_raw是核实估值，其他价为空|
|close_adj|float / 供应商后复权元每股|东方财富hfq收盘；停牌延续由valuation_method明确区分|
|volume|float / 股|原始手数×100；核实停牌延续时为0|
|amount|float / 元|原始日成交额；核实停牌延续时为0|
|tradable_status|string枚举|observed_trading / before_listing / confirmed_suspended / missing_unknown；前者仅证明有成交，不保证买卖可执行|
|status_source|string|状态证据相对路径，或positive_volume/unknown说明|
|valuation_method|string枚举|vendor_close / verified_suspension_carry / missing|
|valuation_valid|int / 0或1|该日复权估值是否可用于收益计算；不是能否交易标记|
|key_conflict, quality_invalid|int / 0或1|同键冲突及价格、OHLC、成交量额的无效标记|
|return|float / 小数|相邻交易日有效复权价比值减1；未知缺失及紧接缺价后的收益为空；锚点无收益|
|missing_reason|string|缺收益原因，空表示有效；锚点标anchor_no_return_required|
|source, adjustment|string|固定eastmoney、hfq，不静默拼源|
|retrieved_at, adj_retrieved_at|string / ISO8601+08:00|逐股原价/复权请求抓取时间|
|is_anchor|int / 0或1|是否仅用于首日收益计算的锚点|

`returns_wide.csv`首列date，余下500列严格按assets顺序；只含研究期，0.02代表2%。`missing_mask.csv`完全同形同序，1=收益缺失、0=有效，包括真实零收益。空值不等于零。`model_returns_wide.csv`仅含推荐100列，按assets中选中资产的原顺序排列。量纲不按供应商涨跌幅字段二次换算。

## 日历、期间与清单

- `calendar.csv`：仅开市日期，包含锚点。`calendar_all_days.csv`还包括周末与休市日。字段date、is_open、is_anchor、period、source；period为anchor/estimation/test。规则见src/trading_calendar.py及冻结官方原页面；原始指数日线日期集用于独立交叉核验。
- `periods.json`：实际估计起止、检验起止、decision_date、proposed_entry_date、proposed_first_return_date、entry_convention、entry_executed=false、validation_split=null、anchor_date、data_version。7月1日建仓日的收益不是持有期首日收益。
- `manifest.json`：版本、请求与实际日期、抓取起止、股票池类型、单位、复权、环境、筛选规则、状态与限制；files存交付数据哈希，source_files存代码与说明哈希。清单自身不递归计算自身哈希。
- `raw_inventory.csv`：path、bytes、sha256覆盖所有冻结原始文件和meta；路径相对数据包根目录。
- `cleaning_audit.csv`：每股原始/复权的处理前条数、完全重复数、冲突日期数。完全重复计数去重，冲突仍保留原始响应。
- `corporate_action_checks.csv`：事件日、计划、公告日期、每股现金与送转、前后原价/复权价、原价收益、复权收益和现金送转算术参照；后者不冒充主源复权公式。
- `quality_summary.json`：名单、成功、合格、子集、T/N、交易日、缺失、状态、实际截至及技术阻塞/限制；其最新完整日期按“全池有效估值”定义，另记“全500只有原始交易条”的日期。
- `acceptance.json`：实际检查结果、离线重建是否执行、技术阻塞、限制及真实组员签认待完成。只有检查实际运行成功才输出。

未经核实的缺价不填零；估计期已证实停牌也不填价。检验期只有逐日确认证据、前值可用、公司行动列表已取且该日无公司行动时才可延续估值；若条件不成立保留缺失并报告。选股只使用估计期信息；更改检验期数据不应改变任何排名或建议名单。
